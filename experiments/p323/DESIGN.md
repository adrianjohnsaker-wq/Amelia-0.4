# P3.23 — Independent-Stream Relational Transduction
Status: PROTOCOL DESIGN / NO REGISTERED RESULT
Date: 2026-10-31

## Question
Does an independently generated incoming stream alter which composed canonical Numogram relations Amelia actually traverses, reproducibly beyond degree-preserving rewires and temporally permuted streams?

## Evidence boundary
P3.22 supports canonical autonomous completion of internally defined composed relations, but not demonstration-driven analogy. This experiment tests input-dependent *transduction*, not decoding accuracy or the existence of external minds. The external stream is independent of the Numogram but its effect, if present, cannot alone establish an ontological Outside.

## Input and provenance
Select a publicly verifiable, append-only external randomness beacon with independently timestamped rounds. Fix its source, round selection, retrieval procedure, SHA-256 of the raw bytes, and byte-to-zone mapping before accessing the registered rounds. Keep raw source bytes and timestamps alongside each derived zone sequence. Do not reuse prior beacon observations for the confirmatory test. The same bytes feed every controller.

Separate discovery and confirmatory round ranges. Discovery may catalogue relations; freeze a small confirmatory set only once before accessing confirmatory rounds. Avoid cherry-picking the signal, relation, lag, or mapping after observing outcomes.

## Comparators
- canonical FULL Numogram with fixed developmental history;
- 24 degree-preserving rewires, with independently matched developmental histories;
- canonical system receiving temporally permuted input (preserve symbols/frequencies);
- canonical system receiving time-shifted input (preserve local statistics);
- canonical system with no incoming input, matched autonomous step budget;
- history-reset control, if PFM contribution is claimed.

Keep gate weights, computational budget, developmental tape, measurement windows and all non-topological mechanisms matched wherever the implementation permits. Record any residual asymmetry as a limitation.

## Readout
Observe transitions without forcing the next zone to match a desired pattern. For each incoming stream window record actual zone paths, the occurrence and dwell of S→C, C→S, S→G, G→S and separately discovered longer motifs, transition entropy, and repeatability under exact replay. The primary contrast must quantify a *difference in relational path distribution attributable to input order*, not merely canonical superiority at completing its own constitutive relations.

Do not define the target as a deterministic function of the same input fed to the system: that would create an answer-key leak. An independent held-out perturbation/replay test must establish whether observed differences are reproducible and input-contingent.

## Causal identification
Use paired identical initial states and identical external bytes across arms. Contrast real temporal order with permutation and shift controls. Measure between-stream differentiation against within-stream replay variance. Compare canonical-specific interaction (real-minus-permuted effect in canonical versus the same effect in rewires), rather than raw canonical completion rate alone.
